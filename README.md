# AsserSnakePy
This repository is cross-platform cuz python is cross-platform but in releases its only for linux debian flavours
# Source code
To use it open terminal and go to my repo source code directory and then type:
```
python3 main.py
```
Or
```
python main.py
```
# Instructions
To move up press W key and down for S and left for A and right for D and controls uses WASD
# Installation
To install go to my releases tab and install the .deb file and open your terminal and then type:
```
sudo dpkg -i assersnakepy-1_0.deb
```
And then open it by clicking the app named AsserSnakePy on your app lists or type on your terminal:
```
assersnakepy
```
And enjoy!
